# Tilqos

**Қате пернетақта орналасымында терілген мәтінді түзетіп, орналасымды өзі ауыстырады.**<br>
Ағылшын, орыс және қазақ тілдері. macOS-қа арналған мәзір жолағындағы қолданба: `ghbdtn` — `привет`-ке, `с2леметс3з` — `сәлеметсіз`-ге айналады.<br>
Бәрі Mac-тың өзінде жұмыс істейді: бұлт жоқ, аккаунт жоқ, желі жоқ, телеметрия жоқ.

*Tilqos* («Тіл қос», яғни «тілді қос») — тәуелсіз, ашық бастапқы кодты жоба. Мақсаты жағынан Punto Switcher-ге ұқсайды, бірақ **Яндекспен байланысы жоқ, Яндекс оны қолдамайды**.

> Қазақша мәтінді кәсіби редактор қараған жоқ. Қате немесе табиғи емес оралым байқасаңыз, [issue ашып](https://github.com/elapen/tilqos/issues/new?template=language_request.yml) («Correction to existing text» таңдаңыз) немесе pull request арқылы түзетуді ұсыныңыз. Ана тілінде сөйлейтіндердің көмегі бізге өте керек.

## Неге Tilqos

Сөйлем бастадыңыз, жоғары қарадыңыз — экранда `привет как дела` орнына `ghbdtn rfr ltkf` тұр. Tilqos мұны байқап, сөздерді қайта жазады, орналасымды ауыстырады, ал сіз теруді жалғастыра бересіз.

Бұл Mac-та күн сайын **ағылшын, орыс және қазақ** тілдерінің бірнешеуінде жазатындарға арналған: екі-үш тілде жазатын авторларға, студенттерге, әзірлеушілерге — Қазақстанда да, одан тыс жерде де.

**Мұнда қазақ тілі — толыққанды тіл, қосымша опция емес.** macOS-та орыс және қазақ орналасымдары **33 орыс әрпінің бәрінде бірдей**, тек сандар қатарында (және бірнеше шеткі пернеде) ерекшеленеді: қазақ орналасымында тоғыз өз әрпі тұрған жерде орыс орналасымында цифрлар тұр:

| Перне | ABC | Орысша | Қазақша |
|---|---|---|---|
| `2` | `2` | `2` | **ә** |
| `3` | `3` | `3` | **і** |
| `4` | `4` | `4` | **ң** |
| `5` | `5` | `5` | **ғ** |
| `=` | `=` | `=` | **һ** |
| `9` | `9` | `9` | **ұ** |
| `-` | `-` | `-` | **ө** |
| `8` | `8` | `8` | **ү** |
| `0` | `0` | `0` | **қ** |

(Мұны тестілер macOS-тың нақты орналасымдарымен тексереді; толық кесте — [docs/KAZAKH.md](docs/KAZAKH.md).) Осыдан үш қорытынды шығады, бүкіл қолданба соған негізделген:

1. **Латын ↔ кирилл** сөзді түгелдей бұзады: `привет` ↔ `ghbdtn`. Оңай танылады.
2. **Орыс орналасымында терілген қазақ мәтінінде** тек тоғыз қазақ әрпі бұзылады, олар цифрға айналады (тоғыздың жетеуі цифр болады, қалған екеуі `=` және `-` белгісіне): `сәлеметсіз` → `с2леметс3з`, `қазақ` → `0аза0`. Кирилл сөздің ішіндегі цифр — өте күшті белгі.
3. **Қазақ орналасымында терілген орыс мәтіні дұрыс көрінеді** (`Астана` — `Астана` күйінде қалады). Түзететін ештеңе жоқ, орналасымды ауыстырудың да қажеті жоқ. Бұл жалған түзетулердің басты көзін жояды.

Қазақ орналасымында цифрлар Option пернесінде тұрады, сондықтан Tilqos **таңбаларды емес, перне басуларды** есте сақтайды: «таңба → таңба» кестесі мұндай жағдайды шығынсыз көрсете алмайды.

<sub>Анимация — сценарийдің иллюстрациясы, экран жазбасы емес, ол **ұсыныс режимін** көрсетеді (терминалдарда және бағдарлама сенімсіз сөздерде әдепкі). «Авто» режимінде детектор сенімді сөз (пресет шегінен жоғары) бос орын басылғанда бірден, карточкасыз ауыстырылады.</sub>

## Не істей алады

- **Өзі түзетеді немесе ұсыныс жасайды.** Детектор сенімді болса, бос орын не тыныс белгісін қойған бойда сөзді ауыстырады; сенімсіз болса, курсор жанында шағын карточка (`было → стало`) шығады, ал **Tab** ауыстыруды қабылдайды. Кез келген басқа перне оны жабады, сөз терілгеніндей қалады.
- **Орналасымды ауыстырады:** түзетуден кейін келесі сөз дұрыс шығады. Түзетілген сөзде тоғыз қазақ әрпінің бірде-бірі болмаса, орыс және қазақ тілдері бірдей көрінеді; сонда Tilqos сіздің баптауыңызға немесе осы қолданбада соңғы рет қолданған кирилл орналасымына қарайды.
- **Нағыз сөзге ешқашан тимейді.** `еще`, `тот`, `her` өзгермейді. URL, жолдар, e-mail, `snake_case` және `camelCase`, `foo(` тәрізді шақырулар, бас әріппен жазылған қысқартулар, `$ # @ \` белгілерінен кейінгі сөздер мүлде өзгертілмейді.
- **Мәзір жолағындағы белгіше** ағымдағы орналасымды перне түрінде көрсетеді (`EN`, `РУ`, `ҚАЗ`), қолданба өшірулі болса күңгірттенеді, рұқсат жетпесе ескерту үшбұрышына ауысады. Мәзірде оның жұмыс істеп тұрғаны сөзбен жазылған, сондай-ақ қосқыш, «Осы қолданбада түзетпеу» және соңғы түзетуді бір басумен болдырмау бар.
- **Әр қолданбаға жеке ереже.** Автотүзету, тек ұсыныс немесе өшірулі (Баптаулар → Қолданбалар). Құпиясөз менеджерлері мен жүйеге кіру терезесі әрдайым өшірулі; терминалдарда әдепкіде тек ұсыныс шығады, оны `⌥Space` арқылы қабылдайды, өйткені Tab-ты терминалдың өзі пайдаланады.
- **«Сақ», «Теңгерімді», «Батыл» пресеттері** (автотүзету/ұсыныс шектері 0.93/0.55, 0.80/0.45, 0.55/0.30); екі шекті де, сөздің ең аз ұзындығын да қолмен баптауға болады.
- **Болдырмау** — `⌥⇧Z`; түзетуден кейін бірден болдырсаңыз, қолданба бұл сөзге тиіспеуді үйренеді.
- **Үйрену** сіздің әрекеттеріңізден: қайтарылған түзетулер, өшіріп қайта терілген сөздер, қабылданған және қабылданбаған ұсыныстар, сіз қалдыратын, бірақ сөздіктерде жоқ сөздер. Хэш түрінде сақталады; өшіруге, бір сөзді немесе бәрін ұмыттыруға болады.
- **Қазақ транслитерациясы** латын ⇄ кирилл (`⌥⇧T`): 2021 жылғы ресми әліпби немесе чаттағыдай практикалық ASCII жазу (`qalaisyz` → `қалайсыз`); үндестік заңы (сингармонизм) мен қазақ морфологиясы ескеріліп талданады, қазақша-орысша аралас мәтінде де.
- **Белгіленген мәтінді түзету / алмасу буферін түрлендіру** — осы пернетақтада терілмеген мәтін үшін.
- **Интерфейс ағылшын, орыс және қазақ тілдерінде**: ол жүйе тілін ұстанады, ал тілді Баптаулар → Негізгі бөлімінде таңдауға болады. Жүйеге кіргенде автоқосу — қалауыңыз бойынша, әдепкіде өшірулі.

| Пернелер | Әрекет |
|---|---|
| `⌥⇧F` | соңғы сөзді түзету (нағыз сөз болса да: өзіңіз сұрадыңыз) |
| `⌥⇧S` | белгіленген мәтінді түзету |
| `⌥⇧Z` | соңғы түзетуді болдырмау |
| `⌥⇧V` | алмасу буферін түрлендіру |
| `⌥⇧T` | транслитерация латын ⇄ кирилл |
| `⌥⇧1` / `⌥⇧2` / `⌥⇧3` | English / Русский / Қазақша |
| `⌥⇧L` | Tilqos-ты қосу / өшіру (өшірулі кезде де жұмыс істейді) |
| `Tab` | ұсынысты қабылдау (терминалдар мен код редакторларында — `⌥Space`) |

Кез келген тіркесімді Баптаулар → Жылдам пернелер бөлімінде өзгертуге болады.

### Бірінші іске қосу (Gatekeeper)

Жинақтарға **ad-hoc түрінде қол қойылған және олар нотаризациядан өтпеген**, сондықтан macOS бірінші іске қосуды бұғаттайды:

1. DMG-ны ашып, **Tilqos**-ты **Applications** қалтасына сүйреңіз де, іске қосыңыз.
2. macOS бас тартқанда: **macOS 14**-те қолданбаны Control-басып (оң жақ батырмамен) → **Open** → **Open**. **macOS 15 және одан жаңасында** бұл жол жоқ: **System Settings → Privacy & Security** бөліміне кіріп, Tilqos туралы хабарламаға дейін төмен жылжытыңыз да, **Open Anyway** батырмасын басыңыз.
3. Терминал ыңғайлы болса және жүктеп алғаныңызға сенсеңіз: `xattr -dr com.apple.quarantine /Applications/Tilqos.app`.

### Рұқсаттар

Пернетақтаны бақылайтын қолданбаға macOS қолмен рұқсат беруді талап етеді.

- **Accessibility (Арнайы мүмкіндіктер)** — берілуге тиісті рұқсат осы (System Settings → Privacy & Security → Accessibility → **Tilqos**-ты қосыңыз; қарсы алу терезесі бұл бөлімді өзі ашады). Ол перне басуларын көру, ұсынысты қабылдайтын пернені «жұтып қою» (Tab қосымша басылмасын деп), курсор алдындағы мәтінді оқу және қате мәтінді ауыстыру үшін керек. (Жүйе интерфейсі басқа тілде болса, бөлімдердің аталуы өзгеше болуы мүмкін.)
- **Input Monitoring (Енгізуді бақылау)** — міндетті емес қосалқы нұсқа: ол тек перне басуларын *оқуға* мүмкіндік береді, яғни қателерді байқап, ұсыныс жасайды, бірақ оларды қолдана алмайды. Accessibility берілген болса, Tilqos Input Monitoring тізімінде мүлде көрінбеуі мүмкін — бұл қалыпты жағдай.
- Басқа ештеңе сұралмайды: экранды жазу да, дискіге толық қолжетімділік те, желі де жоқ.

> **Жаңартудан кейін рұқсатты қайта беріңіз.** macOS рұқсатты қолданбаның код сәйкестігіне байлайды, ал ad-hoc қолтаңбасы әр жинақта әртүрлі болады. Tilqos-тың жаңа нұсқасын орнатқаннан кейін тізімдегі ескі жол қосулы болып көрінуі мүмкін, бірақ енді әрекет етпейді. Tilqos-тан шығып, Privacy & Security → Accessibility тізіміндегі **Tilqos** жолын жойыңыз (**−**) немесе `tccutil reset Accessibility io.github.elapen.tilqos` командасын орындаңыз, Tilqos-ты қайта ашып, рұқсатты қайтадан беріңіз. Толығырақ және «ештеңе болмай жатса» не істеу керек екені — [docs/PERMISSIONS.md](docs/PERMISSIONS.md) файлында.

Tilqos-ты Finder, Dock немесе `open -a Tilqos` арқылы іске қосыңыз, шеллден емес: macOS рұқсат сұрауын қолданбаны іске қосқан процеске жазады.

System Settings → Keyboard → Input Sources бөлімінде **ABC (немесе US), Russian және Kazakh** орналасымдарының кемінде екеуі қосылған болуы керек; Tilqos тек сізде бар орналасымдар арасында ауыстырады.

## Шешім қалай қабылданады

Шешім дәлелдерге сүйенеді, күштісінен әлсізіне қарай (барлық егжей-тегжей мен сандар — [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md) файлында):

1. **Терілген нәрсе — нағыз сөз бе?** Онда ол автоматты түрде ешқашан өзгертілмейді.
2. **Сол пернелердің басқа орналасымдағы түрі — нағыз сөз бе?** Орналасымнан бұзылған жол ешбір тілде сөз емес (`ghbdtn`), ал оның түрлендірілгені — сөз (`привет`). Бренд пен терминдерде керісінше. Түзетудің қауіпсіздігі осы асимметрияға сүйенеді. «Нағыз сөз» — hunspell сөздіктеріндегі сөз формалары (тек бастапқы сөздер емес, түбірлер мен жалғау ережелері), сіздің өз сөздігіңіз және бренд тізімі.
3. **Қысқа сөздер үшін — жиілік.** Үш әріпті түзету тек тілдегі ең жиі сөздердің біріне түскенде ғана қабылданады: `ult` → `где` иә, `afk` → `фал` жоқ.
4. **Контекст.** Көрші сөздердің және курсор алдындағы мәтіннің әліпбиі (латын не кирилл) шешімді бір жаққа қарай бұрады, бірақ өзі шешпейді.
5. **Құрылым.** Кирилл сөздің ішіндегі цифр не дефис (`с2лем`) — сөздіктер не айтса да, орыс орналасымында терілген қазақша. Қазақ морфологиясы (`десеңіздер` = `десе` + `ңіз` + `дер`) оны растайды.
6. **Әріптік триграмма модельдері — ең соңында**, ешбір сөздікте жоқ сөздер үшін, және тек ұсыныс ретінде, автоматты түрде ешқашан.

Сөз тек сіздің орналасымдарыңыздың **ешқайсысында** әріп болмайтын пернемен аяқталады, сондықтан `,skj` (`было`) және `[jhjij` (`хорошо`) екіге бөлінбейді.

|---|---|
| Дұрыс терілген сөздердің өзгергені | **0 / 1 858** |
| Дұрыс терілген сөйлемдердің өзгергені | **0 / 132** |

**Сандарға сенбес бұрын мынаны оқыңыз.** Корпусты автор жазған, шешім тұрақтылары да дәл соған қарап таңдалған, сондықтан бұл *оқыту үлгісіндегі* нәтижелер, тәуелсіз тест емес. Қазақ бөлігі шағын (мысалы, әр бағытқа 20 қазақша сөйлемнен). Корпус — күнделікті лексика; жаргон, код, есімдер және қатты аралас чаттарда нәтиже нашарлау болады. Симуляция нақты детекторды macOS-тың нақты орналасымдарымен іске қосады, бірақ нақты қолданбаларда емес. Нәтижелерді [docs/ACCURACY.md](docs/ACCURACY.md) ішіндегі пәрмендермен қайталауға болады; басқа өнімдер туралы ештеңе айтылмайды, CPU мен жад көрсеткіштері жарияланбайды, өйткені репозиторийде оларды өлшейтін ештеңе жоқ.

## Құпиялылық

Қате орналасымды байқау үшін Tilqos басылған әр пернені бақылайды, сондықтан оның олармен не істейтіні төменде дәл жазылған. Толық мәлімет пен уәделердің шектері — [docs/PRIVACY.md](docs/PRIVACY.md) файлында.

- **Терілген сөз буфері тек жадта тұрады.** Ол теру тоқтағаннан кейін 5 секундтан соң (таймермен), қолданба ауысқанда, Return, Tab, Escape және соған ұқсас шекараларда, құпиясөз өрістерінде, экран құлыпталғанда және ұйқы режимінде тазаланады.
- **Болдырмау тек соңғы түзету(лер)ді сақтайды**, жадта, көп дегенде 2 минут; олар экран құлыпталғанда не ұйқы режимінде, қолданбадан шыққанда және қолданба ауысқанда өшіріледі.
- **Алмасу буферіне тек оны қажет ететін әрекеттер ғана тиеді** (белгіленген мәтінді түзету, транслитерация, буферді түрлендіру). Бұрынғы мазмұны қайтарылады. Жасырын немесе уақытша деп белгіленген мазмұн (құпиясөз менеджерлері) ешқашан оқылмайды. 10 000 таңбадан ұзын мәтін еленбейді.
- **Терілген мәтін, алмасу буферінің мазмұны және терезе тақырыптары журналға ешқашан жазылмайды.**
- **Жергілікті сақталады:** баптаулар, қолданбаларға арналған ерекшеліктер, сіз қосқан ерекшелік сөздер (қарапайым мәтінмен) және үйренген сөздік — **тұздалған 64-биттік FNV-1a хэштері** түрінде. Бұл хэштер криптографиялық тұрғыдан *қайтарылмайтын емес*: файлды оқи алатын адам қысқа, жиі кездесетін сөздерді болжай алады. Баптауларда «Барлық ерекшелік сөздерді тазалау…» және «Үйренгеннің бәрін ұмыту…» әрекеттері бар.
- **Желіге қатынау жоқ, телеметрия жоқ, автожаңарту жоқ.**
- **Қорғалған енгізу (secure input) қосулы тұрғанда ештеңе оқылмайды және журналға жазылмайды** (macOS-тағы құпиясөз өрістері және Secure Event Input қосатын кез келген нәрсе). Оны қоспайтын өрістер бұл тетікпен қорғалмайды.

Шектер: сондай рұқсаты бар басқа бағдарлама Tilqos көретіннің бәрін көре алады; жүйе қолданба құлағанда жад дампын жаза алады; жинақтар нотаризациядан өтпеген, сондықтан бақылау сомаларын тексеріңіз немесе бастапқы кодтан жинаңыз. Құпиялылық қателері — қауіпсіздік қателері: [SECURITY.md](SECURITY.md) файлын қараңыз.

## Windows (эксперименттік)

`windows/` қалтасында сол қозғалтқыштың Go-ға көшірілген нұсқасы бар (тек стандартты кітапхана, x64 және ARM64). Ол хабарландыру аймағында тұрады, жылдам пернелері — `Pause`, `Shift+Pause`, `Alt+Pause`, `Alt+Scroll Lock` (Windows-та Alt+Shift — орналасымды ауыстыру), ұсыныстарды Tab не Insert қабылдайды, ал стандартты Edit/RichEdit өрістеріндегі мәтін ауыстырар алдында тексеріледі.

**Мәртебесі: эксперименттік.** Ол Mac-та жиналған және тексерілген (кросс-компиляция); барлық эталон деректерде Swift қозғалтқышымен бірдей шешім қабылдайды, бірақ пернетақта ұстағышы, `SendInput`, алмасу буфері, трей және қалқымалы ұсыныс коды **автор нақты Windows-та ешқашан іске қосып көрмеген**. Орындалатын файлға қол қойылмаған (SmartScreen ескертеді). Онда браузерлердегі құпиясөз өрістері танылмайды. Тексеріп көріп, не шыққанын айтсаңыз өте жақсы болар еді: [windows/README.md](windows/README.md) файлында жинау, macOS-тан айырмашылықтар, шектеулер және қолмен тексеру тізімі бар.

```bash
cd windows && ./build.sh        # Go 1.25+ керек; macOS немесе Linux (кросс-жинау); Windows-та: .\build.ps1
```

## FAQ

**Бұл кейлоггер ме?** Жұмыс істеу үшін ол әр пернені оқиды — міне, осы мәтін, [docs/PRIVACY.md](docs/PRIVACY.md) және бастапқы код сондықтан бар. Терілген сөз буфері тек жадта тұрады, мәтін журналға жазылмайды, желілік код жоқ.
**Жаңартудан кейін жұмыс істемей қалды.** Accessibility рұқсатын қайта беріңіз (жоғарыда қараңыз).
**Дұрыс терген сөзімді өзгертіп жіберді.** Бірден `⌥⇧Z` басыңыз: сөз ерекшеліктерге қосылады да, енді олай болмайды. Қайталана берсе — «Сақ» пресетін таңдап, issue ашыңыз.
**Ештеңе болмай жатыр.** [docs/PERMISSIONS.md](docs/PERMISSIONS.md#when-nothing-seems-to-happen) бөлімін қараңыз: *осы* жинаққа берілген рұқсат, кемінде екі орналасым, қолданбаның режимі, фокустағы құпиясөз өрісі.
**Неге нотаризация жоқ?** Ол үшін Apple Developer ID сертификаты керек; жинау скрипттері оны қолдайды, бірақ сыналмаған. Көмектессеңіз қуаныштымыз.
**Басқа тілдер болады ма?** Мүмкін: [CONTRIBUTING.md](CONTRIBUTING.md#adding-a-language) және «Language request» issue пішінін қараңыз.
Қосымша — [docs/FAQ.md](docs/FAQ.md) файлында.
