Tilqos — установка
==================

1. Перетащите Tilqos в папку Applications (ярлык рядом).

[[NOT_NOTARIZED]]
2. ПЕРВЫЙ ЗАПУСК: нажмите на Tilqos правой кнопкой -> «Открыть»,
   затем подтвердите «Открыть» в диалоге.

   Обычный двойной клик macOS заблокирует: приложение не проходило
   нотаризацию Apple.
   Правый клик -> «Открыть» нужен только один раз.

   Если диалога нет: Системные настройки -> Конфиденциальность и
   безопасность -> прокрутите вниз -> «Всё равно открыть».
[[/NOT_NOTARIZED]]
[[NOTARIZED]]
2. Откройте Tilqos из папки Applications.
[[/NOTARIZED]]

3. Tilqos попросит разрешение Accessibility («Универсальный доступ») —
   оно нужно и для чтения нажатий, и для замены набранного слова.

   Нажмите «Открыть настройки», найдите Tilqos в списке и включите
   переключатель, затем вернитесь в окно Tilqos: остальное произойдёт
   само. Если Tilqos нет в списке, нажмите «+» под списком и выберите
   Tilqos в папке Applications.

   Input Monitoring выдавать НЕ нужно: Accessibility его перекрывает,
   и в том списке приложения может не быть вовсе — это нормально.

4. Откроется обучение с живой практикой — там можно
   сразу попробовать всё руками. Открыть заново: меню -> «Обучение».

5. Иконка появится в меню-баре рядом с часами. Строка состояния
   вверху меню становится зелёной, когда всё работает.

Язык интерфейса: английский, русский или казахский — в Настройках -> Основные.


Горячие клавиши
---------------
  ⌥⇧F   исправить последнее слово
  ⌥⇧S   исправить выделение
  ⌥⇧Z   отменить последнее исправление
  ⌥⇧V   исправить текст в буфере обмена
  ⌥⇧1 / ⌥⇧2 / ⌥⇧3   English / Русский / Қазақша
  Tab   принять подсказку (в терминалах и IDE — ⌥Space)


Приватность
-----------
Tilqos следит за нажатыми клавишами, чтобы заметить неверную раскладку.
Вот что он с ними делает:

  - Нет доступа к сети, нет телеметрии, нет проверки обновлений.
  - Набранное хранится только в памяти. Оно очищается не позднее чем через
    5 секунд без набора, при смене приложения, на Return, Tab, Esc и подобных
    клавишах, в полях для паролей (пока включён защищённый ввод macOS) и при
    блокировке или сне Mac.
  - «Отмена» хранит последние исправления в памяти не дольше 2 минут и
    стирает их при смене приложения или окна (в том числе собственного окна
    настроек Tilqos), блокировке или сне Mac и выходе.
  - Буфер обмена используется только действиями, которым он нужен, а его
    прежнее содержимое возвращается. Скрытое или временное содержимое
    (менеджеры паролей) никогда не читается: действие ничего не делает, с
    сигналом. Текст длиннее 10 000 символов игнорируется.
  - Набранный текст, содержимое буфера обмена и заголовки окон никогда
    не пишутся в журнал. По умолчанию пишутся только предупреждения и ошибки.
  - На диске: настройки, правила для приложений, добавленные вами
    слова-исключения (обычным текстом) и выученные слова (хеши с солью,
    64 бита; это не шифрование, короткие распространённые слова может
    угадать тот, кто прочитает файл).

Подробнее: Настройки -> О программе.
